04 · Methodology note

How these figures are defined and updated

Data definition
Every public metric states what is being counted, where it comes from, what period it covers, and when it was last updated.
Sample size
China Pilot: more than 50 internal-test participants. Global Advisor: no feedback responses have been recorded, so no average and no percentage is published.
Last updated
Collection of Global Advisor metrics has not started, so there is no update date to report yet.
Anonymous
Feedback is anonymous and optional. No name, email, phone, address, IP address or browser fingerprint is collected.
Exploratory
Early and exploratory evidence. These figures should be interpreted as early, exploratory evidence rather than public-user statistics.
  • Counts start from the real recorded data. No baseline number is added to make a figure look larger.
  • Free-text feedback is never published automatically. An anonymous quotation can only appear after manual review.
  • Impact data follows the same traceability principle as the scoring: every published number must be traceable to its source.

Decision support only. Not engineering design, installation quote, or legal advice. Local installers must confirm sizing and safety.
