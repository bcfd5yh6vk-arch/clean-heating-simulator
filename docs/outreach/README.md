# 游园会印刷件

给自然教育游园会用的海报和小卡。二维码指向全球版中文页：<https://climate.ponderin.cn/?lang=zh>

| 文件 | 用途 | 打印 |
|------|------|------|
| `fair-poster.html` | 大海报：我的故事 + 今天的气候教育 | A2；出 A1 时放大 141% |
| `fair-cards.html` | 一张 A4 上 4 张小卡 | A4，打开背景图形后裁开 |
| `qr-climate.svg` | 同一只二维码 | 不要改指向 GitHub |

本地：`npm run dev` 后打开 `/outreach/poster` 和 `/outreach/cards`。

网站上的配套功能在全球版选点之后：地图点完，会出现十二个月色格，再用三张图卡讲气候、物候、为什么。物候只从月均温和降水推，不写当地物种。
