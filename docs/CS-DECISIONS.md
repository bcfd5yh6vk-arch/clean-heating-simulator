## D1 · 地理解析加国家约束（代码，2026-08-23，commit cc9222e）

**状态**：OPEN（待 Guo review）

**决策**：`docs/src/scoring/dataPoint.ts` 的 `Geography` 增加可选 `country_iso3`；
`resolveScoringValue` 匹配非 country 级条目时，条目带国家标注的必须与查询国家一致，

不报错、只算错，且本轮就要写入中国数据，不修就是明知埋雷。

**影响面**：无国家标注的旧条目行为完全不变（测试夹具依赖此分支）；对现有 216 条测试零破坏。

**撤销**：revert commit cc9222e（但撤销后不得再写入任何中国 admin1 数据）。

## D2 · 燃料燃烧因子的口径（数据，2026-08-23，commit fb972b3）

**状态**：OPEN

**决策**：`fuel_emission_factors.json` 用 IPCC 2006 GL Vol.2 Ch.2 **Table 2.5（居民部门）**缺省值，
CO2e = CO2 + 28·CH4 + 265·N2O（**AR5 GWP100**，UNFCCC 决定 18/CMA.1 要求各国清单采用的口径）。
散煤按 Other Bituminous Coal，confidence=low（煤种差异大）。
biomass 与 district_* 无可引用公开缺省值，如实缺席。

**为什么是裁定而非照抄**：「kgCO2e」在选定 GWP 集之前无定义；居民部门的 CH4/N2O 缺省值
与电厂锅炉差一个量级（散煤炉 CH4=300 kg/TJ），选错表会系统性低估散煤排放。

**撤销**：换 GWP 集或换表只改 `scripts/fetch_emission_factors.py` 顶部常数重跑。

## D7 · 设备性能与存量基线的口径（数据，2026-08-23）

**状态**：OPEN

**决策**（`technology_performance.json`，仅美国地理覆盖）：

1. **候选设备**：ENERGY STAR 认证列表（骨架 preferred_sources 点名的来源）按 P25/P50/P75 聚合，
   value=P50。HSPF2/SEER2/CEER ÷ 3.412、AFUE ÷ 100 换算为无量纲季节效率。
   **已知口径偏差**：认证集是市场高效端，P25 ≈ 认证门槛，不是全市场存量分布——逐条写在 aggregation_method。
2. **baseline:electricity 供暖 = 1.0**：电阻加热的物理定义（§7.4 TECH_OBJECTIVE_RULE，全部 44 国）。
   G3 的 heat_pump 与 electric_heating 现状都落到这个键（引擎按载体建基线），
   热泵现状家庭的有用需求会被低估约 2/3——需要 G3 增加追问才能根治（同 §3.3 类问题）。
3. **燃气/燃油/房间空调存量基线 = 联邦最低能效标准**（10 CFR 430.32，逐字转录 + 引句入库，仅 USA）：
   燃气暖炉 80.0 AFUE（存量以暖炉为主，锅炉 82 已注）、燃油暖炉 83.0、
   房间空调 CEER 10.9（8,000–13,999 Btu/h 档，2014–2026 存量标准——新标准 2026-05-27 起生效，
   但存量基线用旧下限是有意选择）。
   **方向性偏差**：2015 年前安装的设备可能低于下限 → 有用需求被低估 → 所有候选的运行费同向低估，
   不改变候选间相对排序的主导项。
4. **中国/欧盟设备性能仍缺**（HSPF2 不得冒充 SCOP/APF）：欧盟 EPREL 要 API key。
   **中国已探明真实数据路径（2026-08-23 更新，不再需要门槛值口径发明）**：
   中国能效标识网备案库（www.energylabel.com.cn）有可程序化批量调用的公开接口
   （列表 + 详情，详情含 APF/额定制热量/制冷制热季节耗电量；无验证码，`tenant-id: 1` 即可），
   且中标院每月发布官方 XLSX 含全量备案号与能效等级（空调 2020.04–2024.12 共 12,036 条）。
   管线设计：XLSX 拿全量备案号 → API 拉数值分布 → 与 ENERGY STAR 同法 P25/50/75。
   **动手前必须解决的一个技术问题**：GB 21455 的 APF 是全年综合指标，
   引擎要的是制热/制冷两个季节效率——需按标准文本从「季节耗电量 + 额定量」拆算，
   属指标语义映射而非口径发明，列批次 3。
   在此之前中国的 Global 流程如实 insufficient_data，
   由 `real-data-smoke.test.js` 钉成显式断言（落地时必须有意识地翻转）。

**验证**：真实数据冒烟测试——伊利诺伊燃气供暖家庭得到完整四维排名
（无风管热泵 fitness 92.7，年运行费 $2044，年排放 4442 kgCO2e）。

## D8 · 美国安装成本：EIA 报告转录 + 机器核验（数据，2026-08-23）

**状态**：OPEN

**决策**（`technology_installed_costs.json`，仅美国，12 台设备）：EIA 设备成本研究附录 A 的
Total Installed Cost 当期 Typical。该 PDF 各节版式不一（列数 7–16、成本区间拆双行、
Typical 列位随标准/ENERGY STAR 列数漂移），实测程序化按列位取数会把燃气暖炉的
Current Standard 列（3,690）当成 Typical（真值 4,150）——静默取错列。
故采用人工转录 + 脚本对原文数字串逐行核验（同 MEE 模式），核验不过整批失败。

**三个口径选择**：
1. **跳过 ashp_ductless**：EIA 表值是单区 12 kBtu/h 机型，当整宅供暖成本会系统性抬高
   该路径的可负担性；明知偏低的值比 null 更危险（null 走 A 维退化，是诚实行为）。
   测试里有专门断言防止它被误加回来。
2. 原文给典型值**区间**的（油炉 3,480–6,820、房间空调 490–640、地源 14,880–23,120）：
   value 取区间中点，low/high 保留原文界——中点是透明可复核的推导，不是编造。
3. 金额为 2022 美元全美代表值，未含州际差异与补贴（IRA 税收抵免等会显著改变实付价，
   规格未定义补贴机制，不擅自扣减）。

## D10 · 中国居民气价：省会代表值 + 低位热值换算（数据，2026-08-23）

**状态**：OPEN

**决策**：气价定价权在地级市，省级条目取**省会城市居民管道气阶梯第一档**（生活用气，
非采暖专项价）；元/m³ → 元/kWh 用《中国能源统计年鉴》折标系数口径的平均低位发热量
35.588 MJ/m³（9.886 kWh/m³）。

**为什么用低位热值**：中国燃气器具能效标准（GB 20665 壁挂炉热效率）以低位热值为基，
「LHV 价 × LHV 效率」在国内自洽；美国侧 EIA 热值与 AFUE 同为高位基（HHV），各自闭环，
引擎不做跨国比价。灵敏度 ±8%（气源差异），逐条标注。

**重要发现（给 Guo）**：北方 8 个省会里 6 个有**采暖专项气价或扩档**（北京壁挂炉采暖
补贴后实际约 1.9 元/m³、天津独立采暖一档 2.76、石家庄采暖期全按一档、沈阳采暖不阶梯、
长春按面积分档、哈尔滨单一价 3.24）。引擎无专项价格机制，一律未采用（记在每条
aggregation_method 与 curated notes）——生活用气价会**高估**北方燃气壁挂炉采暖的运行费，
方向与电价那条观察一致：对清洁取暖产品是保守偏差，但影响不小，值得产品层面处理。

## D11 · 中国设备性能：备案库全量抓取与指标拆算（数据，2026-08-24）

**状态**：OPEN

**背景**：D7.4 探明真实数据路径后的批次 3 执行。全链路：
中标院 2024-12 官方备案包（universe）→ `scripts/crawl_energylabel.py`
（能效标识网备案库公开接口逐条取详情，~2.2 req/s 限速+断点续爬）→
`scripts/fetch_tech_performance_cn.py`（指标拆算+分布聚合+合并写盘）。

**逐条口径裁定**：

1. **universe = 中标院 2024-12 官方备案包**（空调 GB 21455-2019 共 12,031 条、
   燃气器具 GB 20665-2015 共 70,393 条），而不是 API 库的「尽力枚举」——
   官方包的完整性由发布方保证，统计总体有明确定义。2025+ 的新备案**不并入**
   （API 深翻页有 3000 行硬上限，2025 年只能拿到部分切片，混入会让总体定义变糊；
   排除最新一年方向上略低估热泵效率=保守）。包内 27 个重复备案号去重。
2. **壁挂炉识别 = GB 25034/20665 型号命名法**：`L1*/LL1*/N1*/LN1*`
   （两用/冷凝两用/单采暖/冷凝单采暖）共 22,377 条入集；`JS*` 系（快速热水器，
   含 LJSQ 冷凝式热水器）47,989 条排除；官方库自带的 33 条 `LIPB` 打字错误
   （L1PB 的 1 打成 I，样本人工核对均为壁挂炉）计入；~270 条非标命名
   （进口机型 VUW/WBN/PH 等与乱码行）**宁缺毋错**排除，量级对分位数无影响。
3. **APF → 制热/制冷季节效率的拆算**（"指标语义映射"，非发明数值；**最终采用固定份额法**）：
   备案数据自洽关系 APF×(CSEC+HSEC)/额定制冷量 的中位数在**所有机型子类**
   （变频/定频/柜挂机/各外资品牌）都钉在 954.5–955 负荷小时——标准的
   「制冷:制热负荷比」是全类目普适常数。制冷季节常数 Kc=623.5 由**单冷机备案直接解出**
   （其 SEER=CSTL/CSEC 与 CSEC、额定制冷量同页给出，n=422，核心 IQR 散布 0.46%；
   全距被窗式/移动式等不同负荷线的少数子类尾部撑大，故哨兵量 IQR）。
   拆算：制冷份额=Kc/K_ref=623.5/954.6=0.6531，每台热泵
   制冷效率=份额×APF×ΣE/CSEC、制热效率=(1−份额)×APF×ΣE/HSEC——
   **铭牌容量不进拆分**：初版逐台按 CSTL=Kc×铭牌容量锚定，全量数据显示铭牌与
   实测的散差（定频可达 ±10%）会让 ~10% 合法机被误杀且散差漏进拆分；
   固定份额法对带内机结果一致、对带外机更忠实。垃圾带 [800,1200] 外才剔除。
   **独立交叉验证**：热泵拆算的制冷 P50=5.91 vs 单冷机直接 SEER P50=5.83（差 1.3%）——
   两条完全独立的测量路径在 1% 量级吻合。

## D13 · 货币一致性守卫（代码·引擎输入层，2026-08-24）
